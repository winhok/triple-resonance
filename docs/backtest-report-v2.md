## 三、结论（按证据强度分级）

### ❌ 作废的 v1 结论

- ~~"60m 样本外 +45.06%，策略真实有效"~~ → 修复后 +21.61%，超额 +0.19pp ≈ 0
- ~~"盈亏比 4.51"~~ → final 段 PF 253（19 笔小样本，无意义）
- ~~"15m 过拟合确认"~~ → 证据不足，只能称"未发现稳定优势"

### ✅ 可以说的

1. **策略 ≈ 买入持有 + 止损保护，没有收益 alpha。** 超额 +0.19pp 在噪声范围内；Exposure 99%、持仓极长。所有数字出自同一条组合曲线、引擎内可复现。
2. **风控改善极轻微**：MaxDD -13.03% vs -13.33%，Sharpe 1.21 vs 1.20——统一口径后，此前"明显更优"的印象主要来自不一致的组合构造。
3. **门槛 3 > 门槛 2 是稳健的**（4/4 数据段方向一致）。但机制是"少交易 → 少摩擦 → 更接近 B&H"，不是预测能力。
4. **live 与 backtest 止损现已同口径**（建仓锁定，不随价格/ATR 漂移）。

### ⚠️ 仍不能说的

- "策略有 alpha"——超额为零量级
- "15m 无效"——样本太短（final 段仅约 17 个交易日）
- "60m 门槛3 在未来有效"——final 段数据在 v1 中被查看过（污染）；
  2024-2026 全为大牛市 + 幸存者偏差，熊市表现完全未知

### 🟢 值得下一步做的

- **底仓 + overlay 结构回测**（如 80% 永久持仓 + 0-20% 信号弹性仓）——
  在统一口径的地基上做，逻辑链才干净
- 真正的 walk-forward（滚动窗口重选参数）
- 更长的 15m 历史需要换数据源（券商 API / Polygon 等）

## 四、对实际使用的意义

**这套信号系统现在能做什么：**

- ✅ 60m 三共振作为**加减仓时点参考**（门槛 3）：牛市中接近持有，急跌中提供止损保护
- ✅ 止损提醒（建仓锁定，不漂移）：实盘最有价值的功能
- ✅ 15m 数据作为盘中观察，不作为决策依据

**不能做什么：**

- ❌ 靠它"做 T 赚钱"：60m 没有超额收益，15m 没有可用证据，yfinance 非实盘级
- ❌ 跑赢躺平：最优配置也只是打平
- ❌ 在熊市保护你：2 年样本全是牛市，未经验证

**每月维护**：重跑 `backtest.py --interval 60m --period 730d`，
观察 final 段超额是否持续为正。连续两期为负即停用信号
（注：相邻两期窗口高度重叠，非独立证据）。
