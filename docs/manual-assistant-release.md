## 本次交付

- `assistant/ledger.py`：独立命名空间 SQLite；成交、仓位、现金、盈亏、事件原子提交。
  成交ID幂等、冲突拒绝、部分成交、Decimal碎股、底仓保护、跨日持仓保留、人工现金确认、对账门禁。
- `assistant/calendar.py`：本地 XNYS 日历；UTC事件、ET交易日、DST、休市与提前收盘。
- `assistant/signals.py`：历史/实时共用决策边界；只使用当时已闭合的数据；分钟完整性、5m关闭、开仓截止与过期检查。
- `assistant/engine.py`：多标的/基准同步、持久化去重、风险位触及复核、行情缺失时仍有尾盘定时提醒。
  提醒不创建成交；手动在分钟中途买入，不把成交之前的本分钟最低价当作持仓期止损证据。
- `assistant/runtime.py`：只引用 Alpaca Market Data 客户端；REST工作线程与WebSocket分离；持续回补、修订bar接入、断流提示；
  队列溢出禁用候选输出但保留计时提醒；回放保留接收与处理时间。
- `assistant/cli.py`：init/register/fill/status/set-risk/reconcile/confirm-cash/plan/watch/replay/export。
- 新回测资金核算：初始资金包括底仓与T现金；现金不每日重置；买入有现金约束；交易净额与资金变化恒等；
  PF区分全亏(0)、无交易(n/a)、只有盈利(inf)；缺少可执行数据不假装平仓。
- Parquet：增量合并、跨进程写锁、唯一临时文件、原子替换、真实字节内容hash和明确右开覆盖边界。
- 新安装入口、版本与CI配置；保留旧观察器和状态表，不静默迁移真实持仓。

## 明确不作出的保证

- 软件操作链路不等于策略优势：`UNVALIDATED` / `RESEARCH_CANDIDATE` 始终保留。
- 分钟风险提醒不是逐笔报价，不保证止损成交价。没有自动下单/自动止损/券商账户读写功能。
- 程序关闭时提醒停止；状态保留不意味着真实账户已平仓。
- 回测按固定的现金、费用、延迟和柱内路径假设运行；不自动模拟券商结算资格、借贷、税务或公司行动的所有账户后果。
- IEX缺分钟不自动认定供应商故障，但不能据此捏造VWAP或可执行价格。
- 历史设计稿及v2报告保留为演进记录，新操作入口和边界以README及本文为准。
