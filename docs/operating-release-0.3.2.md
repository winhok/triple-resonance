# 0.3.2 手动日 T 助手整体验收

基线：`05ca62d1fd46a8224c472b6dfc832803fc802a32`，即 PR #1 合并后的 main。
本次解决上一轮 review 的三项缺口，不重写策略、不调整收益参数、不接下单账户。

## 变更

1. **账户级阻断**：所有标的的操作异常均在计算计划之前检查，包括本地零仓位但实际数量不一致的标的。未处理的退出锁也阻止其他标的新增计划。
2. **独立原因与恢复**：数量、现金、对账、保护参数各自恢复，不能用一次股份对账解除现金异常。旧布尔值迁移保守处理。实际成交保留，台账不凭提示清仓。
3. **剩余退出费**：现有每个未平 T 仓预留价差亏损及退出费用，历史实际手续费保留在已实现盈亏，不重复扣费。旧策略配置默认以往返费作为保守退出费预留，可在新初始化时显式给出非对称退出估算。
4. **一致快照**：风险计划/台账导出在单一事务中读取。监控本地处理与外部CLI登记之间有事务边界，录制捕获每次决策实际可见的状态。
5. **完整录制**：初始状态、REST回补、live/updated bar、timer、source状态、交易日历和外部台账变更都记录；默认新文件写入、逐帧序号与哈希、正常停止写结束记录。
6. **隔离验证回放**：同一调度器处理记录；逐帧核对输出与状态哈希；成功后才创建新的回放DB。已有DB拒绝打开，失败不发布台账，旧bar-only记录不冒充完整回放。
7. **运行边界**：流构造/连接失败也不中断本地尾盘检查；异常文本不输出潜在凭据。已知断流/队列溢出时暂停候选。启动时包括已有T持仓，并保留原有时点/数据门禁。
8. **性能**：未开启录制时不扫描完整审计台账；开启录制时按本连接变更数与SQLite data_version缓存快照，外部CLI变更可被检测。落盘只保存外部状态增量而不是每次完整台账。

## 新增回归覆盖

`tests/test_operating_release.py`：真实SQLite账户级门禁、局部修复不能洗掉其他异常、旧库迁移、退出费反例（10美元预算不能批准11美元预计损失）、多仓/部分成交费用、嵌套事务回滚、午间回补产生的信号可重现、外部连接登记成交与风险修改、尾盘无行情计时、修订bar/断流、现有数据保护、损坏/截断/未封口/乱序文件拒绝、内容正确但输出不一致时拒绝、时钟回退、磁盘错误和CLI回放。

`tests/test_runtime_release.py`：实际watch循环 + 单参数SDK形状的fake callback，连接构造失败、无行情尾盘提醒、录制回放一致、旧录制文件在启动worker前被拒绝。

本地针对上述新增场景执行38项通过。本地环境无法从网络拉取完整仓库或安装Alpaca/Parquet依赖，使用已读取的核心领域/信号接口做离线运行；全仓库测试、旧PR回归、完整依赖安装以本次提交的GitHub CI为准，不把本地子集结果冒充全量。

CI验收命令：`python -m pytest -q`、`python tests/test_backtest_engine.py`、`python -m pip check`、`t-assist --help`。

## 不由测试证明的事项

没有登录用户行情账户、没有执行任何交易、没有重跑用户的全量真实历史数据。Setup A仍为UNVALIDATED；分钟触及提醒不是可保证成交的实时止损。新参数仅描述费用/安全边界，不是收益优化。

回放验证表示匹配版本内的输入、输出与本地台账可重现，不表示历史行情与实际市场完全一致。断电或硬杀进程产生未结束录制，默认拒绝认证其完整性；已有记录和真实台账不被删除。

首次部署需要配置自己的行情凭据、确认账户资金规则并观察实际延迟。这是运行环境验收，不是另一个未完成的代码功能清单。
