# 策略参数与调参指南

> 当前用的是**经典默认值**，不是优化结果。这份文档说明每个参数为什么是这个值、什么时候该改、
> 以及怎么验证改动是变好还是变坏。

---

## 一、参数现状

| 参数 | 默认值 | 作用 | 来源 |
|------|--------|------|------|
| K 线周期 | 15m | 主时间尺度 | 日内 T 的常用粒度，比 5m 噪音少，比 30m 信号少 |
| 取样长度 | 10 天（约 260 根） | 保证 EMA26/MACD 充分预热 | 指标需要约 3 倍周期的长度才稳定 |
| RSI | 14，阈值 30/70 | 超买超卖 | Wilder 原始设定 |
| MACD | 12 / 26 / 9 | 动量与转折 | Appel 原始设定 |
| EMA | 9 / 21 | 短期趋势方向 | 9/21 是日内常用组合 |
| 金叉回溯 | 3 根 | 只认"刚发生"的交叉 | 防止追已经走完的旧信号 |
| 固定止损 | -3% | 兜底 | 经验值 |
| ATR 止损 | 1.5 × ATR(14) | 自适应止损（默认） | 波动大时给更多空间 |

### 为什么 RSI 买入区间是 35–65 而不是 <30

RSI < 30 确实是超卖，但在下跌趋势里"超卖之后还有更超卖"。三共振的设计意图是**趋势 + 动量 + 位置**三重确认，
所以：

- `35 ≤ RSI ≤ 65`：健康区，趋势和动量已经确认，位置还没走极端 → 标准加仓点
- `RSI 从 <30 上穿回 30`：真正的超卖反弹起点 → 允许进，但要配合另两个条件

同理卖出侧用 ≥65 而不是 >70：不等极端超买才走，65 以上就开始考虑减仓。

## 二、什么时候该调参

| 现象 | 可能原因 | 调整方向 |
|------|---------|---------|
| 信号太频繁、反复打脸 | 震荡市，EMA 缠绕 | 拉长 EMA（如 9/21 → 13/34），或提高门槛只做 3/3 |
| 信号太稀少 | 参数太钝 | EMA 缩短（9/21 → 5/13），或把回溯放宽到 5 根 |
| 一进场就回撤 | 追高，RSI 区间太宽 | 买入 RSI 上限定到 60 |
| 止损太容易被扫 | ATR 倍数太小 | 1.5 → 2.0，或改用日线 ATR |
| 赚小亏大 | 没有移动止盈 | 加移动止损：浮盈 >2% 后止损上移至成本价 |

## 三、回测结论 v2（2026-09-07 执行引擎修复后重跑，详见 docs/backtest-report-v2.md）

> v1 回测报告结论**已作废**：存在入场当根漏止损、信号出场时序错误两个执行 bug
> 及统计口径错误。修复后 v1 的"60m 样本外 +45.06%"缩水为 final 段 +21.61%，
> 且对 B&H 超额仅 +0.17pp ≈ 0。

v2 采用三段验证（train 50% 选参 → validation 25% 确认 → final 25% 一次性报告）
+ 64 组完整网格（门槛 2/3 为受控变量）+ pooled 全量统计 + 组合权益曲线。

**1. 门槛 3 > 门槛 2 是最稳健的发现（paired 隔离变量）。**
四个数据段（60m/15m × train/validation）中门槛 3 在 22-28/32 组基线优于门槛 2，
方向全部一致。但其机制是"少交易 → 少摩擦 → 更接近持有"，不是预测能力。

**2. 60m 门槛3 配置没有收益 alpha，只有轻微风控价值。**
final 段：策略 +21.61% vs 等权 B&H +21.56%（超额 +0.17pp ≈ 0）；
MaxDD -12.74% vs -13.33%；Sharpe 1.40 vs 1.18。Exposure 99%、
平均持仓约 138 个交易日——本质是"买入持有 + 止损保护"。

**3. 15m 未发现稳定样本外优势，但不能判死刑。**
60 天数据 final 段仅约 17 个交易日，超额 +1.46pp 但 10bps 成本即转负。

**当前引擎默认**：60m + 门槛3 + EMA9/21 + ATR1.5（候选配置，非"已验证"）。
回测选出的最优配置为 EMA5/13 止损3% 门槛3 趋势关，但其优势在噪声范围内，
不构成换参依据。

**三个前提**：样本仅 2 年大牛市（熊市未知）；全部标的为当前存活龙头
（幸存者偏差，历史收益或被高估）；final 段数据在前次实验中被查看过
（严格 forward test 需未来新数据）。

### 何时重跑回测

- 每月一次：`backtest.py --interval 60m --period 730d`
- 改动引擎/参数后先跑 `test_backtest_engine.py`（4 项执行时序回归测试）
- 若 final 段超额持续两期为负，停用信号（注：相邻两期窗口高度重叠，非独立证据）

## 四、已知失效场景

| 场景 | 表现 | 应对 |
|------|------|------|
| 震荡市 | EMA 反复交叉，MACD 频繁金叉死叉 | 只做 3/3 强信号，或直接停手 |
| 跳空开盘 | 指标基于连续价格，跳空会让信号失真 | 开盘前 15 分钟不出信号 |
| 财报/重大事件 | 技术面完全失效，波动由消息驱动 | 财报日不做 T，或只减不加 |
| 低流动性标的 | 15m K 线可能长时间无成交 | 只做日均成交额 > $1B 的标的 |
| 盘前盘后 | 15m 数据只覆盖常规交易时段 | 明确告知用户信号对应的是常规时段 |

## 五、与 invest-stock 配合的正确姿势

```
1. invest-stock 选股     → 这只基本面有没有雷、值不值得持有
2. invest-intraday 择时  → 在选定标的里找 15m 级别的进出点
3. 冲突时以本 skill 为准 → 止损是硬约束，基本面再好也先离场
```

**不要反过来**：不要因为 invest-stock 说"这家公司护城河很宽"，就在 15m 信号转空时死扛。
两个框架的时间尺度不同，混用会导致该止损时不止损。
